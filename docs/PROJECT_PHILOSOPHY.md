# Project Philosophy

1. **Design Before Code**
   Every feature, schema, and engine must be designed logically before a single line of infrastructure code is written.

2. **Resume-Worthy Architecture**
   The codebase must demonstrate senior-level engineering practices:
   - Clear separation of concerns (Engines vs. Services vs. Controllers).
   - Defensive programming (strict schema validation, state transition logic, environment variable validation at startup).

3. **Active Discovery > Passive Listing**
   In critical health scenarios, we push notifications to mathematically ranked donors rather than waiting for them to browse a dashboard.

4. **The "Engineer Intelligence" Goal**
   The purpose of building this project is not just to have a working application, but to cultivate a true software engineering mindset. This means:
   - Attempting the code before asking for answers.
   - Forming hypotheses for why code behaves a certain way.
   - Understanding every architectural decision so it can be defended in an interview.
